Fonctions actuelles :
- Catalogue Supabase avec catalogue local de secours.
- Panier et commande invité avec paiement à la livraison.
- Vérification du stock et calcul du total côté serveur.
- Espace administrateur protégé par Supabase Auth et le rôle admin.
- Gestion du catalogue, du stock et des statuts de commande.
- Préparation manuelle d'un message WhatsApp.
- Interface responsive mobile et ordinateur.

Attention :
- L'annulation d'une commande ne restaure pas automatiquement le stock.
- Aucun paiement en ligne n'est activé.
- Ne jamais placer une clé Supabase Secret/service_role ou un mot de passe dans GitHub ou le code public.
- Les visuels du dépôt sont des concepts graphiques ; vérifier les produits, prix, formulations, livraisons et mentions légales avant toute vente.
